# Grocero Case Study

Eine deutschsprachige Product-Management-Case-Study über Grocero, einen Konzept-Prototyp für die automatisierte Planung des wöchentlichen Lebensmitteleinkaufs.

Die Case Study dokumentiert den Weg von Discovery und vier qualitativen Interviews über Problem Reframing und MVP-Priorisierung bis zum interaktiven Prototyp, Geschäftsmodell und zur Roadmap.

## Lokale Entwicklung

Voraussetzungen: Node.js und pnpm.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## Produktions-Build

```bash
pnpm run build
```

Die statischen Dateien werden im Verzeichnis `dist/` erzeugt.
